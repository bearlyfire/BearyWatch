# BearyWatch

Аналитика EPGP. Аддон для игрового сервера Sirus. WOW 3.3.5
Требует установленного аддона EPGP

## 🚀 Установка
1. Перейдите в раздел [Релизы (Releases)](https://github.com/bearlyfire/BearyWatch/releases) в правой части этой страницы.
2. Скачайте чистый архив `BearyWatch.zip` из самого свежего релиза.
3. Распакуйте архив напрямую в папку игры: `World of Warcraft\Interface\AddOns\`.

## ☕ Поддержать проект
Модификация полностью бесплатна и создается на добровольных началах.
При наличии свободного времени буду улучшать аддон и исправлять ошибки. Исправлять цвет фона, делать возможность изменения размера окна и прочие перламутровые пуговицы не планируется.
Если аддон вам помог и вы хотите отблагодарить автора, вы можете сделать это двумя безопасными способами:

* **В игре:** Отправить внутриигровое золото на почту персонажу **Медведж** на реалме **[SIRUS_x5]**.
* **Напрямую:** Оставить произвольную сумму в качестве подарка на развитие через [сервис CloudTips](https://pay.cloudtips.ru/p/aff01756).
